# MCat

Prova de conceito para catalogar mensagens recebidas do bot Telegram Music Downloader e estudar o encaminhamento de mensagens para um chat de destino.

A aplicação não descarrega nem processa ficheiros de áudio. A versão inicial observa mensagens e guarda metadados localmente. A seleção de Playlist e dos resultados permanece manual.

Consulte a documentação de instalação que será adicionada ao projeto.
